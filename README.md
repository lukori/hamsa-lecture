# איזה מזל, הרצאה קצרה

A 4-minute talk by Luka Or about the "איזה מזל" hamsa exhibition, made as one HTML page.

Open `index.html` in Chrome (works offline), press **F** for full screen.

- Next: → / ↓ / PageDown / Space / Enter / click. Back: ← / ↑ / PageUp.
- Some slides wait for a press: "אהלן" on slide 1, the rolling words (press stops on "מעצב אופטימי"), and both videos (first press plays, the next moves on).
- `#N` in the address opens slide N.

`assets/` holds resized copies of the photos, the transcoded videos (balkan trimmed to 30s) and the IBM Plex Sans Hebrew font. The original source files are not in this repo.
